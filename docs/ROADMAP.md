# 토타시 영어 개발 청사진

- 기준 버전: 1.1.0
- 작성일: 2026-11-05
- 목표: 회화 실력을 키우는 앱을 유지하면서, 실력이 쌓이면 OPIc도 준비할 수 있게 만든다.
- 시험 일정: 정해지지 않음. 회화에 바로 도움이 되는 기능을 먼저 만들고, 시험 전용 기능은 뒤에 둔다.

## 원칙

1. 하단 이동 버튼, 한국어 음성 명령, 리퀴드 글래스 디자인 등 `NEXT_PHASE_SPEC.md`의 원칙을 유지한다.
2. 탭 구조(홈, 학습, 기록, 설정)는 유지하고, 새 학습은 `STUDY_MENU`에 추가한다.
3. 교재와 다른 서비스의 문제, 답안을 복제하지 않는다. 콘텐츠는 직접 작성한다.
4. 앱 레벨과 AI 피드백은 연습용 지표다. 실제 등급을 예측하거나 보장하지 않는다.
5. 문장 통암기보다 답변 틀과 표현을 익히게 한다.
6. AI 비용은 월 한도 안에서 쓰고, AI 없이도 기본 학습은 오프라인에서 된다.
7. OPIc 형식은 만들기 직전에 공식 자료로 다시 확인한다.

## 단계별 내용

### 1단계: 안정화와 실사용 점검

- 실제 API 키로 AI 교정을 확인한다.
- 이어 듣기 1.5초, 자동 넘김 기본 시간을 실제 사용 결과로 조정한다.
- 학습 화면에서 "이 문장 어색해요"를 표시하고, 설정에서 목록을 복사할 수 있게 한다.
- 신고된 표현, 단어, 예시를 고친다.

### 2단계: 길게 말하기

회화와 OPIc 모두에 가장 중요한 기능이다.

- 레벨별 말하기 질문을 직접 작성한다. 일상, 일, 집, 여가, 여행을 다룬다.
- 질문 듣기 → 답변 틀 보기(선택) → 말하기 → 다시 듣기 → 다시 도전
- 말한 시간, 인식된 문장, 단어 수, 긴 멈춤 횟수를 보여 준다.
- 목표 시간을 고른다(30초, 1분, 2분).
- 토타시가 "조금만 더 말해 봐!"처럼 이어 말하기를 돕는다.
- 녹음은 기기에만 저장하고 동기화하지 않는다. 최근 답변만 보관한다.

**기술 확인:** 안드로이드에서 녹음과 음성 인식을 동시에 쓰지 못할 수 있다. 먼저 실제 기기에서 시험한다. 안 되면 설정에서 녹음 또는 인식 방식을 고르게 한다. 음성 인식은 발음을 정확히 평가하지 못하므로 점수로 쓰지 않는다.

### 3단계: AI 답변 피드백

- 인식된 답변을 AI가 고치고, 더 자연스러운 표현과 이어 말할 질문을 제시한다.
- 고친 문장 일부를 복습 카드로 저장할 수 있게 한다.
- 한 번에 긴 답변을 보내므로 호출 비용을 표시하고 월 한도를 지킨다.

### 4단계: 유형별 말하기

- 유형: 자기소개, 묘사, 일상 습관, 비교, 과거 경험, 인상 깊은 일, 변화, 의견
- 유형마다 답변 틀, 연결 표현, 질문 세트를 제공한다.
- 표현과 단어를 유형에 연결해 다시 활용한다.

### 5단계: AI 역할극

- 상황: 카페, 호텔, 병원, 회의, 전화, 문제 항의
- 토타시가 상대 역할을 맡아 쉬운 영어로 대화하고, 끝난 뒤 한국어로 정리해 준다.
- 말문이 막히면 한국어 힌트를 요청할 수 있다.
- 오프라인이거나 한도를 넘으면 정해진 대화 연습으로 대체한다.

### 6단계: 콘텐츠 마무리

- AL 단어와 예시, NL~NH 단어와 예시를 채운다.
- 예시 문장을 표현당 8개에서 차츰 늘린다.
- 신고가 많은 영역을 우선 고친다.

### 7단계: OPIc 준비

- 학습 탭에 OPIc 묶음을 추가한다.
- 목표 등급(IM, IH, AL)에 따라 앱 레벨 목표와 추천 학습을 조정한다.
- 설문 항목 고르기를 연습하고, 겹치는 주제를 묶어 준비 범위를 줄인다.
- 내가 고른 주제에 맞춰 2~4단계의 질문을 우선 낸다.

### 8단계: 모의 인터뷰

- 토타시가 면접관을 맡는다.
- 설문, 자기 평가, 문항 진행, 시간 제한, 난이도 조정을 공식 안내에 맞춰 구현한다.
- 끝난 뒤 답변 전체를 한 번에 AI에 보내 잘한 점과 고칠 점을 받는다.
- 기능, 정확성, 내용과 맥락, 답변의 양과 구성을 참고 관점으로만 쓰고, 등급을 판정하지 않는다.

### 9단계: 마무리

- 약한 유형과 자주 틀리는 표현을 기록 탭에 보여 준다.
- 기존 앱 파츠로 옷장 보상을 추가한다.
- 메뉴, 설정, 속도를 정리한다.

## 하지 않기로 한 것

- 항목별 점수나 예상 OPIc 등급 표시
- 교재 목차와 답안 복제
- 탭 구조 전면 변경
- 문장 통암기 스크립트 제공
- 리그전, 다른 사용자 경쟁, 앱스토어 출시
- 별도 문법 교재 기능. 필요하면 AI 교정 뒤에 짧은 설명으로 넣는다.

## 순서를 바꾸는 조건

- **시험 일정이 3개월 이내로 잡히면:** 7, 8단계를 3단계 다음으로 앞당긴다.
- **녹음과 음성 인식을 함께 쓸 수 없으면:** 2단계 범위를 조정한다.
- **어색한 문장이 많으면:** 6단계의 검수를 앞당긴다.
- **AI 비용이 월 1달러를 넘으면:** 호출 횟수와 답변 길이를 줄인다.
